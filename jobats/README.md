# Resume Scoring System 
Resume Scoring System , gives you score Accordingly 
Choose a job role to target ,know you gap skills and get plan for it

To run this project locally 
use 
```
git clone https://github.com/omnhinge/Job_Seeker
cd jobats
cd backend
node server.js
```
now in other terminal
```
cd jobats
cd frontend
npm start
```
Use your own API key to get accurate Results
the one used here is sample 
find it in 
```
Job_Seeker/jobats/backend/.env
```
Paste your API key in that env file and use it
